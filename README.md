## О проекте

`culinary_recipes_nextjs` - сайт с авторизацией для просмотра/добавления/редактирования рецептов.

В проекте используются следующие технологии:

-   `React.js`
-   `Next.js`
-   `Zustand`
-   `Typescript`
-   `Zod`
-   `TailwindCss`
-   `Heroui`
-   `Prisma`
-   `PostgreSQL`
-   `Next-Auth`
-   `bcryptjs`

## Запуск проекта

```
npm install - устанавливаем зависимости
npm run dev - запуск проекта в dev режиме

```
